# Adivina el numero

## Descripcion
En este proyectos se recrea el juevo adivina el numero, el codigo genera un numero al azar entre el 1 al 100 donde el juador debera adivinar el numero, para que ayudar el jugador se le dira si el numero que puso es mayor o menor al numero secreto, solo tendra 10 intentos si los usa todos ya no podra adivinar y se le dira cual era e numero misterioso

## Caracteristicas
Las caracteristicas de este juego es:
-el jugador solo tiene 10 intentos
-el numero es generado al azar
-se le informa al jugador si su numero es mas alto o bajo
-al momento de ganar o perder puede jugar de nuevo

## Tecnologias usadas
para este proyecto usamos lo siguiente:
-html
-java
-css
